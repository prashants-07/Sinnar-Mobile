# Image provenance

These WebP images are optimized copies of the JPEG files supplied in the existing Sinnar Mobile repository. The originals are preserved at the repository root. No stock-image licenses are asserted: ownership and redistribution rights were not included in the original repository. The shop owner should confirm rights before publication or replace any image that cannot be licensed. No new third-party photos were downloaded.

Run `python scripts/optimize_images.py` after installing Pillow. The maximum image dimensions are 1200 × 1200; metadata is removed during encoding. Product photographs illustrate collections and do not assert specific inventory.
